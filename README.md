# Mezuniyet Projesi

Bu projede ilginizi çeken bir alanı seçiyorsunuz ve o size kariyer önerileri veriyor. Botu çalıştırmak için "!kariyer" demeniz yeterli. Bir de "!ara" komutu var, bu komutun sonuna Teknoloji, Sanat veya Sağlık sözcüklerini getirerek bu alanla alakalı meslekleri görebiliyoruz

## Kariyer önerilerinde; 
Detaylı rehber iste butonuna basarsanız, size o alan ile ilgili kurs ve proje önerileri verir.
Danışmanla görüş butonuna basarsanız bir danışmanımız yakında sizinle iletişime geçecek diyor.
